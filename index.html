TON Connect Toolkit

Test bench for TON Connect — wallet connection, TON transfers, Jetton & NFT transfers, batch messages, signData / signMessage flows, on mainnet or testnet.

Network

Select the network this toolkit targets. Every request (sendTransaction, signData, signMessage) will carry this network ID and the wallet will refuse a mismatch.

Testnet mode is active. Only use testnet assets on testnet. Mainnet transfers are irreversible.

Wallet connection

Not connected

Send TON raw messages

Uses the official messages request shape. Addresses are normalized to TEP-2 friendly form and amounts converted to nanoTON.

The app reads SendTransaction.maxMessages from the connected wallet and automatically splits the batch into multiple requests. Each request requires a separate wallet approval. 254 is a protocol ceiling, not a universal wallet limit.

Send Jetton TEP-74

Requires the sender Jetton Wallet address (not the Jetton Master). The transfer body is built per TEP-74 with forward_ton_amount = 1 nanoTON.

Send NFT TEP-62

Builds a TEP-62 ownership-assignment body. Attached TON is used for forward fees and the response destination.

Signing

signMessage is not part of the base TON Connect protocol and is only supported by a few wallets. The button will fail gracefully if your wallet doesn't declare the corresponding feature.
