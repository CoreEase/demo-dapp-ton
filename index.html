Send TON — Single message or batch transfer raw messages

This page uses the official messages request shape. Addresses are normalized to TEP-2 friendly form and TON amounts are converted to nanograms.

254 is not a universal wallet limit. The app reads SendTransaction.maxMessages from the wallet and automatically splits the batch into multiple requests when needed. Each request requires a separate wallet approval.
